# جمع الأصول من النت — صور · مقاطع · أيقونات

المشاهد اللي فيها **شي حقيقي** (مكان · منتج · حيوان · شخص عام · حدث) أقوى بصورته الحقيقية من أي رسمة.
`scripts/28_assets.py` يدوّر بمصادر مجانية موثوقة، يعطيك **ورقة وحدة مرقّمة**، وينزّل اختيارك بدقته الكاملة ويسجّل رخصته.

> **لو `stockImages: false` بملفه — لا تجيب شي من النت.** والتسمية معه: «مصادر مجانية موثوقة» — لا أسماء مواقع (القاعدة ٨٥).

## ⛔ متى تجيب — لا تنتظر يطلب
بالمونتاج الكامل، **بعد ما تخطط المشاهد وقبل البناء**:
1. امشِ على السكربت جملة جملة وعلّم كل **اسم ملموس** يقوله (مدينة، أكلة، جهاز، حيوان، علامة، مكان شغل…).
2. لكل واحد: هل صورته الحقيقية تقول أكثر من الرسمة؟ غالباً إيه للأماكن والأشياء والأحداث.
3. **الهدف:** أصل حقيقي واحد على الأقل لكل ~١٠ ثواني بالمقطع الكامل (لو تفضيلاته تسمح) — موزّعة، مو كلها ورا بعض.
4. اجمعهم **دفعة وحدة** (عدة `search` بجولة وحدة)، ثم اعرض عليه قائمة قصيرة: «جبت ٦ صور و٢ مقاطع لهاللحظات — هذي الورقة».

## الأوامر
```bash
python3 scripts/28_assets.py <work> search "camel desert sunset"                 # صور (عمودية أول)
python3 scripts/28_assets.py <work> search "city traffic night" --kind video     # مقاطع
python3 scripts/28_assets.py <work> search "rocket" --kind icon                   # أيقونات SVG (الملوّنة أول)
# اقرأ assets/_cand/<slug>.jpg (ورقة وحدة) واختر
python3 scripts/28_assets.py <work> pick camel-desert-sunset 3 --name camel --cut # --cut = بلا خلفية → camel_cut.png
python3 scripts/28_assets.py <work> icon twemoji:flag-egypt noto:trophy          # أيقونات بأسمائها (أعلام الدول: twemoji:flag-<country>)
python3 scripts/28_assets.py <work> credits                                       # سطور الإسناد (لو الرخصة تطلبها)
python3 scripts/28_assets.py <work> clean                                         # امسح المرشّحين بعد ما تخلص
```
- **ابحث بالإنجليزي** وبكلمات بسيطة (٢-٣ كلمات). ما لقيت؟ أعمّ («dromedary» ← «camel»)، أو من زاوية ثانية («coffee beans» بدل «Yemeni coffee»).
- **الأشياء الحقيقية بأسمائها** (مَعلم، مدينة، شعار، شخصية عامة) يلقاها الأرشيف الحر — ابحث بالاسم الإنجليزي الرسمي.
- **المقاطع:** بلا مفتاح المصدر محدود. لو يبي مقاطع ستوك كثيرة، اعرض عليه مرة وحدة يسوي مفتاح مجاني (دقيقتين)
  ويحطه بـ`<بياناته>/keys.json` ← `{"pexels": "…", "pixabay": "…"}` — هنا بس تقدر تسمّي الموقع لأنه هو اللي بيسجّل.

## ⛔ الفحص قبل ما يدخل الفيديو
| | |
|---|---|
| **قيوده** (القاعدة ١١) | الصورة كاملة بالدقة الكاملة — والمقطع **ورقة الفريمات كاملة** (`<اسم>.check.jpg`) مو عيّنة |
| **لا كتابة تُقرأ غلط** | لافتات بلغة ثانية · شعار تجاري بسياق سلبي (القاعدة ٨٥③) |
| **واضحة وكبيرة** | ≥ 1080 بالضلع القصير للملء · الصغيرة داخل كرت بس |
| **تمثّل الكلام** | لو تحتاج شرح عشان تنفهم — مو هي |
| **الرخصة** | CC0 · ترخيص المصدر الحر = بلا شي · **BY / BY-SA = سطر إسناد** بكابشن البوست (`credits`) — قله |

## الاستعمال بالمشاهد
- **صورة ملء الشاشة** مع كلمتها بقطع حاد (القاعدتان ٢٣ و١١٤) · `<Img>` لا خلفية CSS (القاعدة ١١١).
- **مقطع**: `<OffthreadVideo muted>` داخل `<Sequence>` من وقت الكلمة — صوته مكتوم دائماً.
- **مقصوصة (`_cut.png`)**: فوق خلفيته الحيّة، أو فوق `Piece` ورق بأسلوب الورق، أو ورا الشخص المقصوص (`references/person-cutout.md`).
- **أيقونة SVG**: `<Img src={staticFile('x.svg')}>` — تتلوّن وتتحرك بلا ما تفقد وضوح. للأسلوب الورقي حطها داخل `Piece` دائري.
- **خلفية للشخص المقصوص**: صورة أو مقطع مكان (`bg` بـperson.json) — ينقله لمكان ما صوّر فيه.
